# 桌宠动画素材（20 段）

来源：用户提供的五张参考图。制作方式：提取角色透明前景，以固定视角执行二维分区形变、移动和道具绘制，再逐帧合成 GIF 和 VP9 Alpha WebM。

每段 640×360 像素、16 帧、1.92 秒、约 8.33 fps。GIF 供预览，WebM 采用 VP9 Alpha，用于透明桌宠渲染。

注意：这是保留原始角色画面的二维分层/局部变形动画方案，复杂的手指精细抓握和全新背面姿态并非三维骨骼动画，请在正式接入前检查视觉适用性。
