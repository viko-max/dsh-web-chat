# 桌宠素材生成提示词（参考 dsh-pet 管线）

> 目标：为 `dsh-web-chat` 桌宠生成**角色一致、透明背景**的动画素材。
> 流程沿用开源项目 [dsh-pet](https://github.com/PC2005-cloud/dsh-pet) 的「提示词 → 绿幕视频 → 透明 webm」三段式：
> ① 用 AI 视频工具（可灵 / 豆包 / Runway 等）按下方提示词生成**绿幕 mp4** → ② 抠像转**透明 VP9-alpha webm** → ③ 按命名放入插件。
> 你只需生成素材交回，插件侧的播放/状态机已就绪。

---

## 0. 插件需要的文件（命名约定）

插件按 `{角色}-{动作}.webm` 加载动画，`{角色}.webp` 作为静态立绘（减少动态效果/加载失败时显示）。

- 角色 id：`blue-chibi`（蓝发 Q 版）、`blue-full`（蓝发全身）、`black-chibi`（黑发 Q 版）、`orange-chibi`（橙发 Q 版）
- 动作 id（状态机已支持）：`idle`（待机）、`thinking`（思考）、`reading`（朗读/说话）、`done`（完成庆祝）、`reaction`（点击回应）

每个角色至少需要 5 段 webm + 1 张 webp，例如：

```
blue-chibi-idle.webm      blue-chibi-thinking.webm   blue-chibi-reading.webm
blue-chibi-done.webm      blue-chibi-reaction.webm   blue-chibi.webp
```

> 建议先做 `blue-chibi` 一套验证风格，再批量套用到其余三个角色（换发色/服装即可，动作复用）。

## 1. 角色设定主提示词（所有动作共用，保证一致性）

把这段作为**每个动作提示词的前缀**，确保同一角色跨动作不变形：

```
【角色固定设定 · 每个镜头都必须严格一致】
一只拟人化的 Q 版鲸鱼娘吉祥物，2.5 头身，圆润可爱，扁平插画 + 柔和赛璐璐上色。
- 头部：大而圆的脸，占身体约 1/2；黑色豆豆眼（竖直椭圆），两团粉色腮红；小巧的微笑嘴。
- 头发：{蓝色/黑色/橙色}长发，齐刘海，发尾微卷；头顶有一撮呆毛。
- 服饰：白色女仆风荷叶边发箍 + 粉色蝴蝶结；浅色连衣裙，裙摆有鲸鱼尾鳍造型。
- 配色：主色 {蓝 #5B8DEF / 黑 #3A3A3A / 橙 #F5A623}，辅色奶白 #FFF6EC，点缀粉 #F7C8D0。
- 线条：干净闭合描边，无杂色；整体高饱和、低对比阴影，适合透明背景叠加。
【画面规范】
- 比例 16:9，背景为纯绿幕 #00FF00，无任何阴影/渐变/道具投影到背景。
- 角色居中，头顶约在画幅 20% 高度、脚底约 85% 高度，大小全程固定。
- 动作全程在画幅内完成；首帧与尾帧均为标准正面站立姿势（便于无缝循环/衔接）。
- 角色边缘清晰、不透明，避免半透明发丝/羽化（利于抠像）。
- 时长 10 秒，镜头固定无推拉。
```

> 把 `{...}` 替换成对应角色的发色与主色。Q 版（chibi）用 2.5 头身；`blue-full` 全身版可改 4 头身、露出完整鲸鱼尾。

## 2. 五个动作的分镜提示词（接在主提示词后）

### 2.1 `idle` 待机呼吸（循环）
```
【动作 · 待机呼吸】0-10s 循环：
0-2s 正面站立，身体随呼吸轻微上下起伏（幅度约 3%），呆毛轻摆。
2-4s 眨眼一次，头微微左倾。
4-6s 回正，右手轻抬挥一下又放下。
6-8s 眨眼，腮红随呼吸微动。
8-10s 回到与首帧完全相同的站立姿势。
要求：首尾帧一致，可无缝循环；无位移、无转身。
```

### 2.2 `thinking` 思考（循环）
```
【动作 · 思考】0-10s 循环：
0-2s 站立，右手食指点下巴，眼睛向上看。
2-5s 头顶浮现一个缓慢旋转的小问号气泡（白色描边），头随思考左右轻摆。
5-8s 问号变成小灯泡亮起，角色眼睛一亮。
8-10s 气泡淡出，回到首帧站立姿势。
要求：气泡为角色附属元素，同样不透明、绿幕背景；首尾帧一致。
```

### 2.3 `reading` 朗读/说话（循环）
```
【动作 · 朗读】0-10s 循环：
0-2s 站立，双手捧一本小书在胸前。
2-8s 嘴巴随说话节奏开合（每秒约 3 次），头部轻微点动，书页偶尔翻动一页。
8-10s 合书微笑，回到首帧站立姿势。
要求：口型清晰但夸张可爱；首尾帧一致，可循环。
```

### 2.4 `done` 完成庆祝（一次性）
```
【动作 · 完成庆祝】0-10s 一次性：
0-1s 站立。
1-3s 双手举高跳起，落地微蹲挤压（Q 弹）。
3-6s 头顶撒出少量星星/彩带粒子，角色开心转半圈。
6-9s 比一个 OK 手势，眨眼。
9-10s 回到标准站立姿势。
要求：粒子为不透明小元素、绿幕背景；尾帧回站立。
```

### 2.5 `reaction` 点击回应（一次性）
```
【动作 · 点击回应】0-10s 一次性：
0-1s 站立。
1-2s 被轻戳般身体一缩、眼睛睁大（惊讶）。
2-5s 害羞地双手捂脸又放开，腮红加深，原地小跳一下。
5-8s 开心挥手，头顶冒一个小爱心。
8-10s 回到标准站立姿势。
要求：表情夸张可爱；尾帧回站立。
```

> 可选扩展动作（插件后续可接入）：`error`（垂头叹气冒汗）、`sleep`（入睡→循环→醒来三段，参考 dsh-pet 睡觉接力规范）、`drag`（被拖拽悬空四肢摆动）。

## 3. 静态立绘 `{角色}.webp`

用同一角色主提示词，改为图像生成：
```
【静态立绘】上述角色，正面标准站立姿势，透明背景（PNG 导出后转 webp），
1024×1024，角色居中占画幅约 70%，边缘清晰不透明，无背景无投影。
```
导出 PNG → 转 `webp`（保留 alpha）。

## 4. 绿幕 → 透明 webm（抠像与转码）

参考 dsh-pet 素材链（任选其一）：

**路线 A · 自动抠像（ffmpeg，人人可复现）**
```bash
# 绿幕抠像 + 缩放为 640×360 播放变体，输出 VP9-alpha 透明 webm
ffmpeg -i 输入.mp4 -vf "chromakey=0x00FF00:0.18:0.08,scale=640:360:flags=lanczos,format=yuva420p" \
  -c:v libvpx-vp9 -pix_fmt yuva420p -b:v 0 -crf 30 -an 输出.webm
```
- `chromakey` 的相似度/混合度（0.18/0.08）按残边情况微调；发丝残边可加 `despill`。
- 必须保留 alpha：`-pix_fmt yuva420p`、`format=yuva420p`。

**路线 B · 手工抠像（含复杂边缘/道具时更精细）**
在 PR/AE 里用 Keylight 抠绿幕，导出 **ProRes 4444 with Alpha 的 .mov**，再：
```bash
ffmpeg -i 输入.mov -vf "scale=640:360:flags=lanczos,format=yuva420p" \
  -c:v libvpx-vp9 -pix_fmt yuva420p -b:v 0 -crf 30 -an 输出.webm
```

**校验**：用支持透明的播放器（Chrome 直接打开 webm）确认背景全透、无绿边、首尾帧站立一致。
